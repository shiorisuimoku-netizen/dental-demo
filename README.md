# 医療機関サイト 制作サンプル集

医療機関のWebサイト制作サンプルです。**実在する医療機関ではありません。**
医院名・所在地・電話番号・診療時間・料金はすべて架空のものです。

診療科によって来院する人の困りごとも必要な配慮も変わるため、
同じ型を使い回さず、構成とデザインを変えて制作しています。

| サンプル | 診療科 | 力点 |
|---|---|---|
| `dental/` | 歯科・矯正歯科 | 自費診療の費用・期間・リスクの書き方 |
| `naika/` | 内科・呼吸器内科 | 発熱時の来院導線、オンライン診療の限界の明示 |
| `seikei/` | 整形外科・リハビリ | 高齢者向けの可読性（18px基準・文字拡大・高コントラスト） |

## このサンプルで示していること

**医療広告ガイドライン（厚生労働省）に沿った構成**で作っています。医療機関のサイトは
一般的な企業サイトと違い、書ける内容に法令上の制約があります。

- 患者の体験談を掲載しない
- 施術前後（ビフォーアフター）の写真を使わない
- 「日本一」「最高」「絶対安全」などの最上級・断定表現を使わない
- 他院との比較をしない
- **自費診療は費用・治療期間・起こりうるリスクをセットで明記する**
- 未承認医薬品・医療機器を用いる場合の説明義務に触れる

`treatment.html` の矯正歯科の項が、これらを最も具体的に示した部分です。

## 設計上の判断

- **人物写真を使っていません。** フリー素材でも「院長」として顔写真を載せると、
  その人物が医師であると誤認されるためです。図はすべてインラインSVGで描いています。
- **当日の診療状況をトップ最上部に置いています。** 患者が最初に知りたいのは
  「今日やっているか」であり、診療時間の表を読ませるより先に答えるべき情報だからです。
- **「対応できないこと」を明記しています。** できることだけを並べたサイトより、
  結果として来院前のミスマッチを減らせます。
- 全ページ `noindex` です。制作サンプルが検索結果に出て、実在の医院と
  混同されるのを防ぐためです。

## 構成

```
index.html            サンプル一覧（案内ページ）
check.js              全ページの一括点検スクリプト

dental/               歯科・矯正歯科（5ページ）
  index.html          当日の診療状況・診療科・初診の流れ
  first-visit.html    持ち物・当日の流れ・費用の目安・FAQ
  treatment.html      矯正の費用/期間/リスク・対応できないこと
  clinic.html         院長より・設備・医院概要
  access.html         経路図・電車/車/バス

naika/                内科・呼吸器内科（3ページ）
  index.html          当日の受付状況・オンライン診療の対象と限界
  fever.html          発熱時の来院手順・救急を優先すべき症状
  access.html         経路図・発熱の方専用入口

seikei/               整形外科・リハビリ（3ページ）
  index.html          相談内容・受診の流れ
  rehab.html          通う回数と期間の目安・費用
  access.html         駐車場の優先スペース・車椅子の方への案内
  assets/font-size.js 文字サイズ切り替え（標準/大/特大・localStorage保存）
```

依存ライブラリなし。ビルド不要の静的HTMLです。

## 点検

```
node check.js
```

全ページについて、`noindex` と架空である旨の表示、医療広告ガイドラインで
問題になる表現、非日本語文字の混入をまとめて確認します。
